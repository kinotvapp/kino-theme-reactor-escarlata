# Reactor Escarlata

Rojo de armadura y dorado de reactor, para genios con traje de metal.

Tema para [Kino](https://github.com/kinotvapp/kino-light). Cambia los colores, el fondo y las formas de toda la app, trae una pantalla de presentación y no se conecta a internet.

En Kino, escribe `kinotvapp/kino-theme-reactor-escarlata` en **Plugins ▸ Agregar un plugin**. Después actívalo en **Ajustes ▸ App ▸ Apariencia**.

Necesita Kino 0.9.80 o superior.
